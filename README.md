# 1cSkills

Репозиторий скиллов и знаний по разработке на 1С:Предприятие 8.3/8.5.

## Структура

```
1cSkills/
├── skills/                          # Готовые скиллы для Claude Code
│   ├── 1c-coding-standards/         # Стандарты кодирования на 1С (из БСП)
│   │   ├── SKILL.md                 # Основной скилл (22 KB)
│   │   └── BSP-EXAMPLES.md          # Примеры кода из БСП (12 KB)
│   └── 1c-http-services/            # Разработка HTTP-сервисов
│       └── SKILL.md                 # MDO, хэндлеры, JSON, отладка
├── learning/                        # Заметки и отчёты сессий
│   └── session-2026-09-09-*.md      # Отчёт по разработке API для UNF
└── .claude/skills/                  # Автозагрузка скиллов
    └── 1c-coding-standards/
        └── SKILL.md
```

## Скиллы

### 1c-coding-standards
Стандарты кодирования на 1С, извлечённые из библиотеки СтандартныеПодсистемы (БСП) UNF.

**21 раздел:**
- Структура модулей, именование, документация
- Обработка ошибок, запросы, JSON
- HTTP-сервисы, расширения, локализация
- Паттерны объектных модулей (документы, справочники)
- АПК-директивы, условные вызовы подсистем

**Источник:** БСП библиотека 1С-Софт (CC BY 4.0, 2025)

### 1c-http-services
Разработка HTTP-сервисов в расширениях 1С 8.5.

**Покрывает:**
- MDO-структура HTTP-сервисов
- Хэндлеры и именование
- Чтение/запись JSON (ЧтениеJSON vs ПрочитатьJSON)
- Шаблоны ответов
- Отладка и тестирование
- Деплой через VRD

## Использование

Скопировать нужный скилл в `.claude/skills/` проекта:
```bash
cp -r skills/1c-coding-standards/ .claude/skills/
```

Или добавить путь в конфигурацию MiMoCode.

## Добавление новых скиллов

1. Создать директорию в `skills/<skill-name>/`
2. Создать `SKILL.md` с YAML-фронтматером
3. При необходимости добавить `references/` или `scripts/`
4. Обновить README.md

## Обновления

Репозиторий постоянно дополняется новыми скиллами по мере накопления опыта работы с 1С.
