## Обзор

**1С:Управление Нашей Фирмой (УНФ)** — типовая конфигурация для малого и среднего бизнеса.

### Направления учёта:
- **Продажи**: ЗаказПокупателя → РасходнаяНакладная → СчетФактура → Оплата
- **Закупки**: ЗаказПоставщику → ПриходнаяНакладная → СчетФактураПолученный → Оплата
- **Производство**: ЗаказНаПроизводство → СборкаЗапасов
- **Склад**: Запасы, перемещения, инвентаризация, ячейки
- **Финансы**: Кассы, банковские счета, платежные поручения
- **CRM**: Воронка продаж, взаимодействия
- **Зарплата**: Начисления, удержания, расчётные ведомости

## Документы

### Цепочка продаж

```
ЗаказПокупателя
  ├── СчетНаОплату
  ├── РасходнаяНакладная (Заказ = ЗаказПокупателя)
  │     └── СчетФактура (ДокументОснование = РасходнаяНакладная)
  └── Оплата (ПоступлениеВКассу / ПоступлениеНаСчет)
```

| Документ | Проводки | Табличные части |
|---------|----------|----------------|
| **ЗаказПокупателя** | ЗаказыПокупателей, ПотребностьВЗапасах | Запасы, РаботыИУслуги |
| **РасходнаяНакладная** | ЗапасыНаСкладах, РасчетыСПокупателями, Продажи, НДС, ПартииТоваров, ДоходыИРасходы, Управленческий | Запасы, РаботыИУслуги |
| **СчетФактура** | НДСЗаписиКнигиПродаж, НДСПредъявленный | Запасы, РаботыИУслуги |
| **СчетНаОплату** | ОплатаСчетовИЗаказов, ПлатежныйКалендарь | Запасы, РаботыИУслуги |
| **АктВыполненныхРабот** | РасчетыСПокупателями, Продажи, ДоходыИРасходы | РаботыИУслуги |

### Цепочка закупок

```
ЗаказПоставщику (ЗаказПокупателя = ссылка на заказ покупателя)
  ├── СчетНаОплатуПоставщика
  ├── ПриходнаяНакладная (Заказ = ЗаказПоставщику)
  │     └── СчетФактураПолученный (ДокументОснование = ПриходнаяНакладная)
  └── Оплата (РасходИзКассы / РасходСоСчета)
```

| Документ | Проводки | Табличные части |
|---------|----------|----------------|
| **ЗаказПоставщику** | ЗаказыПоставщикам, ПотребностьВЗапасах | Запасы, Услуги |
| **ПриходнаяНакладная** | ЗапасыНаСкладах, РасчетыСПоставщиками, Закупки, НДС, ПартииТоваров, ДоходыИРасходы, Управленческий | Запасы, Услуги |
| **СчетФактураПолученный** | НДСПредъявленный, НДСЗаписиКнигиПокупок | Запасы, Услуги |
| **ДополнительныеРасходы** | Закупки, РасчетыСПоставщиками | Расходы |

-- Организации

-- Номенклатура

    УНИКАЛЬНЫЙИДЕНТИФИКАТОР(Ссылка) КАК GUID
ИЗ Справочник.Номенклатура

-- Договоры контрагента

ИЗ Справочник.ДоговорыКонтрагентов

### Документы

```sql
-- Заказы покупателей
ВЫБРАТЬ Номер, Дата, Контрагент, Организация, СуммаДокумента, Проведен
ИЗ Документ.ЗаказПокупателя
УПОРЯДОЧИТЬ ПО Дата УБЫВ

-- Расходные накладные
ВЫБРАТЬ Номер, Дата, Контрагент, Организация, СуммаДокумента, Проведен
ИЗ Документ.РасходнаяНакладная
УПОРЯДОЧИТЬ ПО Дата УБЫВ

-- Заказы поставщикам
ВЫБРАТЬ Номер, Дата, Контрагент, Организация, СуммаДокумента
ИЗ Документ.ЗаказПоставщику

-- Приходные накладные
ВЫБРАТЬ Номер, Дата, Контрагент, СуммаДокумента
ИЗ Документ.ПриходнаяНакладная

-- Табличная часть документа
ВЫБРАТЬ Запасы.Номенклатура, Запасы.Количество, Запасы.Цена, Запасы.Сумма
ИЗ Документ.РасходнаяНакладная.Запасы КАК Запасы
ГДЕ Запасы.Ссылка = &СсылкаНаДокумент
```

### Регистры

```sql
-- Продажи (обороты за период)
ВЫБРАТЬ Номенклатура, Контрагент,
    КоличествоОборот, СуммаОборот, СебестоимостьОборот
ИЗ РегистрНакопления.Продажи.Обороты(&ДатаНачала, &ДатаОкончания)

-- Запасы (остатки)
ВЫБРАТЬ СтруктурнаяЕдиница КАК Склад, Номенклатура,
    КоличествоОстаток, СуммаОстаток
ИЗ РегистрНакопления.Запасы.Остатки()

-- Доходы и расходы (расходы по статье)
ВЫБРАТЬ ЕСТЬNULL(СУММА(СуммаРасходовОборот), 0) КАК Расход
ИЗ РегистрНакопления.ДоходыИРасходы.Обороты(&ДатаНачала, &ДатаОкончания)
ГДЕ (ВЫРАЗИТЬ(АналитикаСубконто1 КАК Справочник.СтатьиДоходовРасходов)).НаименованиеОПиУ
    ПОДОБНО "%ИмяСтатьи%"

-- Взаиморасчёты с покупателями (остатки)
ВЫБРАТЬ Контрагент, Договор, ДолгОстаток, ПредоплатаОстаток
ИЗ РегистрНакопления.ВзаиморасчётыСПокупателями.Остатки()
ГДЕ ДолгОстаток > 0

-- Цены номенклатуры
ВЫБРАТЬ ВидЦен, Номенклатура, Цена
ИЗ РегистрСведений.ЦеныНоменклатуры.СрезПоследних(&Период)

-- Остатки заказов покупателей
ВЫБРАТЬ Заказ, Номенклатура, КоличествоОстаток
ИЗ РегистрНакопления.ЗаказыПокупателей.Остатки()

-- Движения документа
ВЫБРАТЬ *
ИЗ РегистрНакопления.Продажи
ГДЕ Регистратор = &СсылкаНаДокумент
```

## Особенности API

1. **Числа**: API возвращает `33,33` (запятая) — парсить на клиенте
2. **Пустые ссылки**: Возвращаются как пустые строки `""`
3. **GUID**: Для поиска/связи используйте `УНИКАЛЬНЫЙИДЕНТИФИКАТОР(Ссылка)`
4. **Кириллица**: Ключи на русском (`Команда`, `ТекстЗапроса`)
5. **Только SELECT**: `EXECUTEQUERY` — только SELECT
6. **Поле Заказ**: В РасходнаяНакладная → `Заказ` = ЗаказПокупателя, в ПриходнаяНакладная → `Заказ` = ЗаказПоставщику
7. **ДокументОснование**: Ссылка на документ-основание (для цепочек)
