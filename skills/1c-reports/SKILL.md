## 15. Template.dcs — Write Clean, Not Copy Dirty (LESSON LEARNED)

### The #1 Rule: Write a Minimal Clean DCS, Don't Copy a Complex One

**Copying a complex DCS (e.g. from Продажи with 6000+ lines) and trying to clean it is a FAILED approach.**
The copied file contains hundreds of stale fields, calculated fields, parameters, templates, and output settings from the source report that cause cascading errors:
- "Поле не найдено 'Документ'" — old field references in output settings
- "Несоответствие типов" — old parameter types don't match
- "Ошибка в запросе" — old ВЫБОР expressions with stale field names

**CORRECT approach: Write a clean minimal DCS (~200-300 lines)** with only the elements your report needs.

### Minimal Working Template.dcs Structure

See the actual working file at:
Расширение2\src\Reports\Расш2_ОтчетПоПредзаказам\Templates\ОсновнаяСхемаКомпоновкиДанных\Template.dcs
(260 lines, clean structure with: dataSource, dataSet with fields+query, totalField, parameters, settingsVariant)

### Key elements of a minimal DCS:

1. **dataSource** — just <name>ИсточникДанных1</name> + <dataSourceType>Local</dataSourceType>
2. **dataSet** with xsi:type="DataSetQuery":
   - One <field> per query output column (with <dataPath>, <field>, optional <role>, <title>)
   - <dataSource>ИсточникДанных1</dataSource>
   - <query> with XML-encoded parameters (&amp; for &, &gt; for >)
3. **totalField** — one per aggregate: <dataPath> + <expression>Сумма(Поле)</expression>
4. **parameter** — <name>, <title>, <valueType>, <value>
5. **settingsVariant** with <dcsset:selection> (selected fields), <dcsset:dataParameters>, <dcsset:outputParameters>, <dcsset:item xsi:type="dcsset:StructureItemTable"> (column+row structure)

### XML Entity Encoding in DCS Query Text

The <query> tag is raw XML, NOT CDATA. Special characters MUST be XML-escaped:

| Character | In DCS XML | In 1C query |
|-----------|-----------|-------------|
| & (parameter) | &amp; | & |
| > (comparison) | &gt; | > |
| < (comparison) | &lt; | < |
| " (string) | " | " |

### Common DCS Errors and Causes

| Error | Cause | Fix |
|-------|-------|-----|
| "Редактирование объекта не поддерживается" | Broken XML or stale copied DCS | Write clean minimal DCS |
| "Поле не найдено 'Документ'" | Old field references from copied DCS | Remove stale field definitions |
| "Несоответствие типов (параметр номер 1)" | Wrong method call or missing element | Check method signatures |
| "Ожидается выражение КОНЕЦ" | Double-double-quotes "" in string literals | Use single " in query strings |
| "Неверные параметры" | Non-existent enum value | Query actual values via HTTP first |
| Ошибка при разборе EntityName | Unescaped & in query | Use &amp; for & |
