# Сессия 2026-09-09: Разработка API для UNF

## Задача
Создание HTTP-сервиса для доступа к базе данных 1С:Управление Нашей Фирмой (UNF) из расширения unfAiAgent.

## Результат
- **Ping**: `GET /hs/test/ping/` → `ok` ✅
- **Query**: `POST /hs/ai/api/` с JSON → массив объектов ✅
- протестированы справочники (Контрагенты, Организации), документы (ЗаказПокупателя), регистры (Продажи, ЗаказыПокупателей)

## Ключевые ошибки и решения

### 1. ПрочитатьJSON(строка) падает в 1C 8.5
**Проблема:** `ПрочитатьJSON(ТелоЗапроса)` вызывает 500 ошибку в контексте HTTP-сервиса.
**Решение:** Всегда использовать объект `ЧтениеJSON`:
```1c
Чтение = Новый ЧтениеJSON;
Чтение.УстановитьСтроку(ТелоЗапроса);
Данные = ПрочитатьJSON(Чтение);
Чтение.Закрыть();
```

### 2. ЗаписьJSON.ОткрытьПоток() не работает
**Проблема:** `ОткрытьПоток()` не доступен в контексте HTTP-сервиса.
**Решение:** Использовать `УстановитьСтроку()`:
```1c
ЗаписьJSON = Новый ЗаписьJSON;
ЗаписьJSON.УстановитьСтроку();
ЗаписатьJSON(ЗаписьJSON, Значение);
Результат = ЗаписьJSON.ЗакрытьИПолучитьСтроку();
```

### 3. containedObjects нельзя удалять из Configuration.mdo
**Проблема:** Удаление `containedObjects` вызывает ошибку "Отсутствует внутренняя информация (узел InternalInfo)".
**Решение:** НИКОГДА не удалять `containedObjects` из Adopted расширений.

### 4. Удаление отчёта из расширения
**Проблема:** Отчёт `ВыборкаЭлементовСправочника` уже существует в базовой UNF.
**Решение:** Убрать из Configuration.mdo и подсистемы, удалить файлы.

### 5. MDO требует шаблон и methods
**Проблема:** HTTP-сервис с только `<name>` без `<template>` не работает.
**Решение:** Всегда указывать `<template>/path</template>` и `<methods>` с `<handler>`.

### 6. Имя функции-хэндлера
**Проблема:** Функция `apiHandle` не вызывалась.
**Решение:** Имя функции ТОЧНО должно совпадать с `<handler>` в MDO (например `apiPOST`, `pingGET`).

## Формат запросов UNF

```sql
-- Справочник
ВЫБРАТЬ ПЕРВЫЕ 10
    Контрагенты.Ссылка КАК Ссылка,
    Контрагенты.Наименование КАК Наименование,
    Контрагенты.Код КАК Код,
    УНИКАЛЬНЫЙИДЕНТИФИКАТОР(Контрагенты.Ссылка) КАК GUID
ИЗ
    Справочник.Контрагенты КАК Контрагенты

-- Документ
ВЫБРАТЬ
    Документ.Номер КАК Номер,
    Документ.Дата КАК Дата,
    Документ.Проведен КАК Проведен
ИЗ
    Документ.ЗаказПокупателя КАК Документ

-- Регистр накопления (обороты)
ВЫБРАТЬ * ИЗ РегистрНакопления.Продажи.Обороты()

-- Регистр накопления (остатки)
ВЫБРАТЬ * ИЗ РегистрНакопления.ЗаказыПокупателей.Остатки()
```
