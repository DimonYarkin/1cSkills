# Сессия 2026-09-10: Формы отчётов и отчёт ОПиУ

## Задача
Создание отчёта "О прибылях и убытках" в расширении unftest с:
- Настройками из регистра сведений (никакого хардкода)
- Динамическим выводом подгрупп
- Формой с периодом и ТабличныйДокумент

## Результат
- Отчёт работает: `/hs/` → отчёт ОПиУ с полной вычислительной логикой
- Форма отображает: поле периода, кнопки, таблицу результата
- Все настройки из регистра `НастройкиОПиУ`

## Ключевые ошибки и решения

### 1. Form.form: элементы не отображаются
**Проблема:** Элементы формы существуют в XML, но не рендерятся на форме.
**Решение:** Элементы `items` должны быть на **верхнем уровне** формы, не вложены в `FormGroup`.

```xml
<!-- ПРАВИЛЬНО -->
<form:Form>
  <items xsi:type="form:FormField">...</items>
  <items xsi:type="form:Button">...</items>
</form:Form>

<!-- НЕПРАВИЛЬНО — элементы не отобразятся -->
<form:Form>
  <items xsi:type="form:FormGroup">
    <items xsi:type="form:FormField">...</items>
  </items>
</form:Form>
```

### 2. SpreadsheetDocumentField не отображается
**Проблема:** Таблица результата пустая.
**Решение:** Использовать `SpreadSheetDocFieldExtInfo` (заглавная S), не `SpreadsheetDocumentFieldExtInfo`.

### 3. dataPath не привязывается к атрибуту
**Проблема:** Поле ввода не связано с атрибутом формы.
**Решение:** Использовать `xsi:type="form:DataPath"` с элементом `<segments>`:
```xml
<dataPath xsi:type="form:DataPath">
  <segments>ПериодОтчета</segments>
</dataPath>
```

### 4. Отчёт не открывает форму
**Проблема:** При открытии отчёта форма не появляется.
**Решение:** Добавить `<defaultForm>` в MDO отчёта:
```xml
<defaultForm>Report.ОПиУ.Form.ФормаОтчета</defaultForm>
```

### 5. UUID с невалидными символами
**Проблема:** `ExportException: Ошибка записи XML реквизита uuid с значением null`
**Причина:** UUID содержал символы `g`, `h`, `i` (допустимы только 0-9, a-f).
**Решение:** Перегенерировать все UUID с валидными hex-символами.

### 6. informationRegisterPeriodicity = Nonperiodical
**Проблема:** EDT не принимает значение `Nonperiodical`.
**Решение:** Для непериодического регистра **убрать** элемент `<informationRegisterPeriodicity>` entirely.

### 7. Удаление containedObjects
**Проблема:** Ошибка "Отсутствует внутренняя информация (узел InternalInfo)".
**Решение:** НИКОГДА не удалять `containedObjects` из Configuration.mdo Adopted расширений.

## Архитектура отчёта ОПиУ

### Регистр сведений НастройкиОПиУ:
| Поле | Тип | Роль |
|---|---|---|
| НомерОПиУ | Число | Измерение |
| НаименованиеОПиУ | Строка(150) | Измерение |
| Группировка | Перечисление.ГруппировкиОПиУ | Измерение |
| Подгруппа | Перечисление.ПодпунктыОПиУ | Измерение |
| ЗначениеОтбора | Строка(500) | Ресурс (статьи через ;) |
| Формула | Строка(200) | Ресурс (=B6, =SUM(B7:B13)) |
| ИсточникДанных | Строка(300) | Ресурс |
| ТипСтроки | Строка(20) | Ресурс (Значение/Формула/Итого/Заголовок) |
| ИсточникРегистр | Строка(50) | Ресурс (Продажи/ДоходыИРасходы) |
| ПолеСуммы | Строка(50) | Ресурс (СуммаОборот/СебестоимостьОборот) |

### 3-пасовая архитектура ObjectModule:
1. **Пасc 1:** Вычисление всех значений из регистров накопления
2. **Пасc 2:** Вычисление формул (=B6, =SUM, =B15+B16-B20+B27)
3. **Пасc 3:** Вывод с проверкой — подгруппа выводится только если данные ≠ 0

## Источники данных в UNF
- **Продажи** → Выручка (СуммаОборот), Себестоимость (СебестоимостьОборот)
- **ДоходыИРасходы** → Все расходы/доходы по статьям (через `НаименованиеОПиУ` в `АналитикаСубконто`)
- **ДоходыИРасходы (сальдо)** → Компенсации маркетплейсов, Сальдо инвентаризации
