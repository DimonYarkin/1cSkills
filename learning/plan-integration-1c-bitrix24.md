# План интеграции 1С:УНФ + Битрикс24

> Дата: 2026-09-10
> Статус: Черновик (планирование)

## 1. Обмен данными

| Направление | Данные | Частота |
|---|---|---|
| **1С → Битрикс** | Контрагенты, Номенклатура, Остатки, Цены, Заказы | по событию / по расписанию |
| **Битрикс → 1С** | Заказы покупателей, Лиды, Обращения | по событию |

## 2. Способы обмена

| Способ | Сложность | Рекомендация |
|---|---|---|
| **REST API Битрикс24** + HTTP-сервис в 1С | Средняя | Рекомендуется |
| **1С-Битрикс: Обмен данными** (готовый компонент) | Низкая | Для стандартных сценариев |
| **Через промежуточную БД** | Высокая | Для сложных трансформаций |
| **ОБД (обмен через XML)** | Средняя | Для пакетного обмена |

## 3. Архитектура (REST API)

```
┌─────────────┐     REST API      ┌─────────────┐
│  1С:УНФ     │ ◄──────────────► │  Битрикс24   │
│  (HTTP API) │                   │  (REST API)  │
└──────┬──────┘                   └──────┬──────┘
       │                                 │
       ▼                                 ▼
┌─────────────┐                   ┌─────────────┐
│ Расширение  │                   │ Вебхуки /   │
│ unfAiAgent  │                   │ Каталог     │
└─────────────┘                   └─────────────┘
```

## 4. Этапы

| # | Этап | Срок | Описание |
|---|---|---|---|
| 1 | **Настройка API** | 1 нед | HTTP-сервис в 1С (уже готов в unfAiAgent), настройка REST API Битрикс24 |
| 2 | **Синхронизация контрагентов** | 1 нед | Выгрузка контрагентов 1С → создание лидов/контактов в Битрикс |
| 3 | **Синхронизация номенклатуры** | 1 нед | Выгрузка каталога товаров с ценами и остатками |
| 4 | **Синхронизация заказов** | 1 нед | Приём заказов из Битрикс → создание заказов покупателя в 1С |
| 5 | **Остатки в реальном времени** | 3 дня | HTTP-запрос из Битрикс для получения актуальных остатков |
| 6 | **Тестирование** | 3 дня | Проверка на тестовых данных, нагрузочное тестирование |
| 7 | **Ввод в эксплуатацию** | 2 дня | Перенос на боевой режим, обучение |

## 5. Ключевые API-эндпоинты

### Битрикс24 (REST):
```
POST /crm/lead.add          — создать лид
POST /crm/deal.add          — создать сделку
POST /crm/contact.add       — создать контакт
POST /crm/product.add       — создать товар
GET  /crm/deal.list         — список сделок
GET  /crm/product.list      — список товаров
POST /crm/order.add         — создать заказ (Интернет-магазин)
```

### 1С:УНФ (уже готово):
```
POST /hs/ai/api/            — EXECUTEQUERY, CREATEDOCUMENT, POSTDOCUMENT
GET  /hs/test/ping/         — проверка доступности
```

## 6. Пример обмена (заказы из Битрикс → 1С)

```php
// PHP вебхук в Битрикс24
$response = Http::post('http://localhost/unf/ru/hs/ai/api/', [
    'Команда' => 'CREATEDOCUMENT',
    'ТипДокумента' => 'ЗаказПокупателя',
    'Данные' => [
        'Контрагент' => $lead['CONTACT_NAME'],
        'Организация' => 'БАЕР ПАК ООО',
    ]

```

## 7. Риски

| Риск | Вероятность | Митигация |
|---|---|---|
| Таймауты при большом объёме | Средняя | Пакетная выгрузка по 100 записей |
| Дублирование данных | Высокая | Проверка по GUID перед созданием |
| Несоответствие справочников | Средняя | Маппинг наименований |
| Ограничения API Битрикс (2 запроса/сек) | Высокая | Очередь запросов, батчинг |

## 8. Требования

- **Битрикс24**: Корпоративная версия или облако с доступом к REST API
- **1С:УНФ**: Расширение unfAiAgent (уже развёрнуто)
- **Сервер**: Доступ по HTTP между серверами 1С и Битрикс24
- **Пользователи**: Создать сервисного пользователя в каждом продукте
